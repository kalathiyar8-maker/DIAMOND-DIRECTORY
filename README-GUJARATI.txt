========================================
  DIAMOND DIRECTORY — Android App
  (કોલ પકડીને પોપ-અપ કરતી નેટિવ એપ)
========================================

આ શું છે:
- સાચી Android એપ છે. ફોન કોલ પતે એટલે, જો નંબર નવો હોય, તો
  આપોઆપ પોપ-અપ આવે — "આ નંબર સેવ કરવો છે?" — નામ, ડિપાર્ટમેન્ટ,
  નોટ ભરીને સેવ કરી શકાય.
- સંપર્ક લિસ્ટ, ડિપાર્ટમેન્ટ ઉમેરો/ડિલીટ (બે વાર કન્ફર્મ), કોલ, એડિટ, ડિલીટ.

--------------------------------------------------
APK બનાવવા શું જોઈએ (એક વાર):
--------------------------------------------------
1. કોમ્પ્યુટર પર Android Studio ડાઉનલોડ કરો (ફ્રી):
   https://developer.android.com/studio
2. Android Studio ખોલો > "Open" > આ ફોલ્ડર
   (DiamondDirectory-Android) પસંદ કરો.
3. પહેલી વાર એ આપોઆપ Gradle અને જરૂરી ફાઈલો ડાઉનલોડ કરશે
   (ઈન્ટરનેટ જોઈએ, થોડી મિનિટ લાગશે).
4. ઉપર લીલા ▶ (Run) બટન દબાવો — ફોન USB થી જોડેલો હોય
   અથવા Emulator પર એપ ઈન્સ્ટોલ થઈ જશે.
5. APK ફાઈલ જોઈતી હોય તો મેનૂ:
   Build > Build Bundle(s)/APK(s) > Build APK(s)
   એ ફાઈલ ફોનમાં કોપી કરીને ઈન્સ્ટોલ કરી શકાય.

--------------------------------------------------
એપ ચાલુ કર્યા પછી (ફોનમાં):
--------------------------------------------------
- "પરમિશન" બટન દબાવો અને આ ચાલુ કરો:
  • Phone / Call log (નંબર વાંચવા માટે)
  • Display over other apps (કોલ પછી પોપ-અપ દેખાડવા)
  • Notifications
- આ પરમિશન વગર કોલ-પોપ-અપ કામ નહીં કરે.

--------------------------------------------------
ધ્યાનમાં રાખવાનું (સાચી વાત):
--------------------------------------------------
1. Call log પરમિશનવાળી એપ Google Play Store પર મૂકવી અઘરી છે
   (Google ના નિયમ). એટલે આ એપ સીધી APK તરીકે ફોનમાં ઈન્સ્ટોલ
   કરવાની (sideload) — Play Store પર નહીં.
2. અલગ અલગ Android વર્ઝન/બ્રાન્ડ (Xiaomi, Samsung...) માં
   બેકગ્રાઉન્ડ પોપ-અપ પર થોડા વધારાના રિસ્ટ્રિક્શન હોય છે —
   ત્યાં "Autostart" અને "Battery: no restriction" પણ ચાલુ કરવું.
3. આ પ્રોજેક્ટ મજબૂત શરૂઆત (starter) છે. ટેસ્ટ કરીને નાના
   ફેરફાર જોઈએ તો કરી શકાય.

જો Android Studio ફાવે નહીં, તો રોજ-બરોજ વાપરવા માટે
web એપ (diamond-directory.html) વાપરો — એ મોબાઈલમાં તરત ચાલે.


==================================================
  APK ની સ્પીડ વિશે (લોડિંગ નહીં, સ્મૂધ)
==================================================
- આ એપ સંપૂર્ણ OFFLINE છે. કોઈ ઈન્ટરનેટ, કોઈ ફોટો-ડાઉનલોડ,
  કોઈ સર્વર કૉલ નથી — એટલે કોઈ "loading" સ્ક્રીન કે સ્પિનર નથી.
- ડેટા ફોનમાં જ (SharedPreferences) સેવ થાય, તરત ખૂલે.
- લિસ્ટ, પોપ-અપ, સેવ — બધું તાત્કાલિક (instant) છે.
- હજારો સંપર્ક થાય ને સ્ક્રોલ ભારે લાગે, તો કહેજો — લિસ્ટને
  RecyclerView માં કરી આપીશ (એથી લાંબા લિસ્ટમાં પણ એકદમ સ્મૂધ).
