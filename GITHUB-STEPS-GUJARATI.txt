==================================================
  GITHUB થી APK બનાવો — કોમ્પ્યુટર/Android Studio વગર
==================================================
GitHub cloud માં આપોઆપ APK બનાવી આપશે. તમારે ફક્ત ફાઈલો
અપલોડ કરવાની. ~5-8 મિનિટમાં તૈયાર APK ડાઉનલોડ કરવા મળશે.

------------------------------------------
સ્ટેપ 1 — GitHub એકાઉન્ટ
------------------------------------------
- github.com પર જાવ > ફ્રી એકાઉન્ટ બનાવો (Sign up).

------------------------------------------
સ્ટેપ 2 — નવી repository બનાવો
------------------------------------------
- ઉપર જમણે "+" > "New repository".
- Name: diamond-directory  (કંઈ પણ ચાલે)
- Public પસંદ કરો > "Create repository".

------------------------------------------
સ્ટેપ 3 — ફાઈલો અપલોડ કરો
------------------------------------------
- આ ZIP ને કોમ્પ્યુટર/ફોનમાં EXTRACT (unzip) કરો.
- નવી repository ના પેજ પર:
  "Add file" > "Upload files".
- અંદરની બધી ફાઈલ-ફોલ્ડર (app, .github, build.gradle,
  settings.gradle, gradle વગેરે) ખેંચીને (drag) મૂકો.
  ** ખાસ: .github ફોલ્ડર પણ અપલોડ થવું જ જોઈએ **
  (એ છુપાયેલું હોય; Chrome માં આખું ફોલ્ડર ખેંચો તો આવી જશે.)
- નીચે "Commit changes" દબાવો.

------------------------------------------
સ્ટેપ 4 — APK ડાઉનલોડ કરો
------------------------------------------
- ઉપર "Actions" ટૅબ પર જાવ.
- "Build APK" નામનું કામ ચાલતું દેખાશે (પીળું ટપકું).
  પૂરું થાય એટલે લીલું ✔ થશે (~5-8 મિનિટ).
- એના પર ક્લિક કરો > નીચે "Artifacts" માં
  "DiamondDirectory-APK" ડાઉનલોડ કરો.
- એ ZIP ખોલો > અંદર "app-debug.apk" મળશે.

------------------------------------------
સ્ટેપ 5 — ફોનમાં ઈન્સ્ટોલ
------------------------------------------
- app-debug.apk ફોનમાં કોપી કરો > ખોલો.
- "Install unknown apps" allow કરો > Install.
- એપ ખોલી, "પરમિશન" બટન દબાવી, નીચેના ચાલુ કરો:
  • Phone / Call log
  • Display over other apps
  • Notifications
- (Xiaomi/Samsung: Autostart + Battery "no restriction" પણ ચાલુ કરો)

તૈયાર! હવે કોલ પતે એટલે નવો નંબર માટે પોપ-અપ આવશે.

------------------------------------------
કંઈ ફેરફાર જોઈએ તો?
------------------------------------------
- repository માં ફાઈલ બદલો > Commit કરો > Actions ફરી
  આપોઆપ નવી APK બનાવી આપશે. Android Studio ની જરૂર નહીં.
